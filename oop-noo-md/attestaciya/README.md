## Общие сведения

**Типы процедур:** стартовая диагностика, текущее оценивание, тематическое
оценивание, промежуточная аттестация, итоговая оценка, портфолио,
психолого-педагогическое наблюдение; внешние — независимая диагностика (МЦКО)
и мониторинги.

**Промежуточная аттестация** проводится по каждому предмету; её формы и
периодичность определяются локальным актом школы («Положение о формах,
периодичности и порядке текущего контроля успеваемости и промежуточной
аттестации обучающихся ГБОУ Школа № 1366»). Промежуточная аттестация —
основание для перевода в следующий класс.

**Итоговая оценка** за год — средневзвешенная отметка всех оценочных процедур
по предмету за учебный год.

**Шкалы оценивания:**
- 1 класс — безотметочная описательная;
- зачётная («зачтено» — «не зачтено»);
- пятибалльная: «5» — отлично (высокий уровень), «4» — хорошо (повышенный),
  «3» — удовлетворительно (базовый), «2» — неудовлетворительно (пониженный),
  «1» — плохо (низкий).

**Общие критерии по письменным работам** (контрольные, тестовые,
практические): «5» — 95–100 % правильных ответов, «4» — 75–94 %,
«3» — 50–74 %, «2» — менее 50 %.
