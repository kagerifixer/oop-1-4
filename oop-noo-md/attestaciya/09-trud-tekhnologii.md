# Промежуточная аттестация: Труд (технология)

> НОО · ГБОУ Школа № 1366 · ФГОС 3.0. Источники: годовой учебный план
> (стр. 1744–1747), «Система оценки…» (стр. 18–73), программа по труду
> (технологии).

## Что нужно сдать (форма промежуточной аттестации)

**Зачёт выполнения практической работы, проект.**

На практике ребёнок изготавливает изделие (практическая работа) и/или выполняет
**проект**, который защищает.

## Когда сдаётся по классам

| Класс | Способ оценки (конец года) | Срок (обычный / ЭНШ) |
|---|---|---|
| 1 | Проект | май / декабрь |
| 2 | Проект | май |
| 3 | Проект | май |
| 4 | Проект | май |

В календаре оценочных процедур: **2 неделя мая — проект по технологии**.
Контрольных работ по технологии нет ни в одном классе (Таблица 3: 0/0/0/0).

## Критерии оценивания

**«5»** — свободное владение обязательной терминологией, информацией о
материалах и технологиях, умение применять их при создании собственных
творческих работ без ошибок и помощи.

**«4»** — умение оперировать обязательной терминологией, знание изученной
информации о материалах и технологиях, выполнение работы по образцу с
незначительными отклонениями в конструкции, использовании материалов, в
аккуратности исполнения.

**«3»** — минимальные знания о материалах и технологиях, слабое владение
терминологией, выполнение работы по образцу с отклонениями от технологии,
небрежно.

**«2»** — учащийся не владеет изученными материалами и технологиями, не знает
соответствующей терминологии, выполняет изделие по образцу с серьёзными
нарушениями технологии.

## Формы текущего контроля по программе

- практическая работа (изготовление изделия);
- проект, творческая работа;
- устный ответ, наблюдение за практической деятельностью.
