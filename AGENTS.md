# AGENTS.md — контекст проекта

Файл для агентов и участников: даёт быстрый вход в контекст, чтобы сразу
отвечать на вопросы по содержанию проекта.

## Что это за проект

Материалы по **Основной образовательной программе начального общего
образования (ООП НОО)** ГБОУ Школа № 1366 (Москва, 2025), реализуемой по
**ФГОС 3.0** на основе федеральной образовательной программы (ФОП НОО).
Программа охватывает **1–4 классы** (есть ускоренный вариант «Эффективная
начальная школа» — ЭНШ, за 3 года).

Исходный документ — PDF на **1811 страниц**. Он сконвертирован в Markdown, а по
каждому предмету собраны справки об аттестации.

## Структура репозитория

```
.
├── AGENTS.md              # этот файл
├── README.md              # общий README проекта
├── src/
│   └── ООПНООФГОС3.0.pdf  # ИСТОЧНИК (11 МБ, 1811 стр.) — не изменять
├── oop-noo-md/            # PDF → Markdown
│   ├── README.md          # оглавление: 63 раздела + номера страниц PDF
│   ├── 01-...63.md        # по файлу на раздел/программу
│   ├── attestaciya/       # 12 файлов: аттестация по предметам
│   ├── assets/            # 21 значимое изображение
│   └── manifest.json      # метаданные (карта разделов и изображений)
└── tools/
    └── convert.py         # скрипт конвертации PDF → Markdown
```

## Главное правило навигации

**Внутренняя нумерация страниц PDF совпадает с номерами страниц в оглавлении
документа** (проверено). Поэтому, зная страницу из `oop-noo-md/README.md`, легко
найти нужный раздел. Каждый файл `oop-noo-md/NN-*.md` начинается со строки-цитаты
вида `> … Страницы PDF: X–Y.`

Карта «раздел → файл → страницы PDF» — в `oop-noo-md/README.md` и
`oop-noo-md/manifest.json`.

## Ключевые факты (шпаргалка)

**Формы промежуточной аттестации** (из годового учебного плана):

- Русский язык — контрольная работа, диагностика
- Литературное чтение — комбинированная работа, пересказ, выразительное чтение
- Иностранный язык (английский) — комбинированная работа, устный зачёт, аудирование
- Математика — комбинированная работа, решение задач, диагностика
- Окружающий мир — комбинированная работа
- ОРКСЭ — зачёт по итогам выполнения проекта (только 4 класс, 1 ч/нед)
- Изобразительное искусство / Музыка / Физическая культура — зачёт выполнения
  практической работы или внешние результаты образовательной деятельности
- Технология — зачёт выполнения практической работы, проект
- Математический практикум, Введение в информатику — зачёт практической работы

**Число контрольных работ за год (1/2/3/4 класс):** русский — 0/4/4/5;
литературное чтение — 0/1/1/1; иностранный — //0/2/2; математика — 0/5/6/6;
окружающий мир — 0/3/3/3; ОРКСЭ — только 4 класс, 0; музыка, ИЗО, технология,
физкультура — 0 везде.

**Итоговая оценка** за год — средневзвешенная всех оценочных процедур.
**Шкалы:** 1 класс — безотметочная описательная; зачётная; пятибалльная.

**Частный пример (музыка, зачёт):** зачёт вокально-хоровой работы ИЛИ внешние
результаты; в конце года — творческая работа (май); критерии «5»–«2» — в файле
`03-…md` (подраздел «Нормы оценивания учебного предмета «Музыка»»). Подробно —
`oop-noo-md/attestaciya/07-muzyka.md`.

## Как устроен конвертер (`tools/convert.py`)

- **Зависимости:** Python 3, `pymupdf`; утилита `pdftotext` (пакет `poppler-utils`).
- **Запуск из корня проекта:** `python3 tools/convert.py`.
- Читает `src/ООПНООФГОС3.0.pdf`, **перезаписывает** `oop-noo-md/` (файлы
  разделов, `assets/`, `README.md`, `manifest.json`). Папку `attestaciya/` **не
  трогает**.
- Пути строятся от расположения `__file__`, поэтому работают при любом имени
  корневой папки и не требуют правок после переименования.
- Как устроена конвертация: заголовки — по размеру/начертанию шрифта; таблицы —
  по векторным границам ячеек; изображения ≥ 200×150 px — в `assets/`; удаляются
  повторяющиеся колонтитулы и номера страниц; Symbol-глифы (`\uf0b7` и др.)
  нормализуются в списки.
- Нумерация строк в `03-…md`, на которую ссылаются документы `attestaciya/`,
  определяется детерминированно. После существенного изменения логики конвертера
  эти ссылки нужно перепроверить.

## Соглашения и ограничения (важно учитывать в ответах)

- Это **автоматическая** конвертация: заголовки и таблицы восстановлены с
  высокой, но не 100 % точностью. В сложных таблицах с объединёнными ячейками
  возможна неточная разбивка по столбцам, но **весь исходный текст сохранён**.
- Сохранность проверена пословно: потери (без учёта намеренно удалённых
  дублирующихся колонтитулов) ≈ 0,05 %.
- При расхождениях приоритет имеет исходный PDF в `src/`.
- В документе встречаются **опечатки самого источника** (например, «внуерочной»,
  «Литературатурное чтение», «е, е, ю, я» вместо «е, ё, ю, я»). Не «исправлять
  молча» — при цитировании сохранять как в источнике и при необходимости
  оговаривать.
- Учебные планы и календари привязаны к 2025/2026 учебному году.
- При ответах на вопросы о содержании **ссылаться на файл и, где полезно, на
  строку**: формат `oop-noo-md/NN-*.md:строка`.

## Типовые задачи

1. **Ответить на вопрос по программе/аттестации** — найти раздел по
   `oop-noo-md/README.md`, открыть нужный файл, процитировать с указанием
   файла/строки.
2. **Обновить `attestaciya/`** — при изменении форм/критериев править
   соответствующий `oop-noo-md/attestaciya/NN-*.md` (конвертер их не
   перезаписывает).
3. **Перегенерировать Markdown** — `python3 tools/convert.py` (см. выше).
4. **Переименование корня** — безопасно: внутренних абсолютных путей к папке нет,
   ссылки относительные.
