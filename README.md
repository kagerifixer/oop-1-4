# ООП НОО, 1–4 классы — ГБОУ Школа № 1366 (ФГОС 3.0)

Материалы по **Основной образовательной программе начального общего
образования** ГБОУ Школа № 1366 (Москва, 2025), реализуемой по **ФГОС 3.0** на
основе федеральной образовательной программы (ФОП НОО). Программа охватывает
**1–4 классы** (включая ускоренное обучение по программе «Эффективная начальная
школа» за 3 года).

Исходный PDF (1811 страниц) переведён в удобный для чтения и дальнейшей работы
Markdown, а по каждому предмету собраны документы об аттестации.

## Структура проекта

```
.
├── README.md              # этот файл
├── src/
│   └── ООПНООФГОС3.0.pdf  # исходный документ (1811 стр.)
├── oop-noo-md/            # сконвертированный в Markdown текст
│   ├── README.md          # оглавление: 63 раздела со ссылками и номерами страниц PDF
│   ├── 01-...63.md        # по файлу на каждый раздел/программу
│   ├── attestaciya/       # аттестация по предметам (что сдать, сроки, критерии)
│   │   ├── README.md
│   │   └── 01-...11.md
│   ├── assets/            # значимые схемы и изображения (21 шт.)
│   └── manifest.json      # метаданные: карта разделов, изображений, оглавление
└── tools/
    └── convert.py         # скрипт конвертации PDF → Markdown
```

## Содержание программы (крупные разделы)

Текст разбит на 63 файла по структуре документа. Ключевые разделы:

1. Пояснительная записка — `oop-noo-md/01-...`
2. Планируемые результаты — `oop-noo-md/02-...`
3. Система оценки достижения планируемых результатов — `oop-noo-md/03-...`
4. Содержательный раздел: рабочие программы всех предметов
   (русский язык, литературное чтение, английский, математика, окружающий мир,
   музыка, ИЗО, труд (технология), физкультура, ОРКСЭ и др.) —
   `oop-noo-md/04-...25-...`
5. Внеурочная деятельность, программа воспитания, коррекционная работа —
   `oop-noo-md/26-...51-...`
6. Организационный раздел: учебный план, графики, календарные планы,
   требования к условиям — `oop-noo-md/52-...63-...`

Полное оглавление со ссылками и соответствием страницам PDF — в
[`oop-noo-md/README.md`](oop-noo-md/README.md).

## Аттестация по предметам

В папке [`oop-noo-md/attestaciya/`](oop-noo-md/attestaciya/README.md) — по
документу на каждый предмет: форма промежуточной аттестации, что именно
сдаётся по годам обучения, сроки, критерии оценивания и формы текущего
контроля. Есть сводные таблицы по всем предметам и распределение контрольных
работ по классам.

## Как получен Markdown

Текст извлечён из PDF и структурирован в Markdown скриптом
[`tools/convert.py`](tools/convert.py):

- заголовки определяются по размеру и начертанию шрифта;
- таблицы восстанавливаются по векторным границам ячеек;
- изображения крупнее 200×150 px сохраняются в `assets/` и вставляются по месту;
- удаляются повторяющиеся колонтитулы и служебные номера страниц,
  нормализуются символы шрифтов Symbol/Wingdings.

**Требования:** Python 3, библиотека `pymupdf`, утилита `pdftotext`
(пакет `poppler-utils`).

**Запуск** (из корня проекта):

```bash
python3 -m pip install pymupdf
python3 tools/convert.py
```

Скрипт читает `src/ООПНООФГОС3.0.pdf` и перезаписывает содержимое
`oop-noo-md/` (файлы разделов, `assets/`, `README.md`, `manifest.json`).
Папка `attestaciya/` не затрагивается.

## Известные ограничения

- Это автоматическая конвертация: заголовки и таблицы восстановлены с высокой,
  но не 100 % точностью. Сложные таблицы с объединёнными ячейками могут иметь
  неточную разбивку по столбцам — при этом **весь исходный текст сохранён**.
- Сохранность проверена пословно: потери текста (без учёта намеренно удалённых
  дублирующихся колонтитулов) — около 0,05 %.
- При расхождениях приоритет имеет исходный PDF в `src/`.
